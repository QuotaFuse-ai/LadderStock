这一版在演示什么

不是最终 UI，是把 P0–P2 的产品形态先摆出来看。所有数字为示例。

P0 先变得好用
  • 21 屏收成 3 个入口
  • 所有回答结论先行
  • 术语点开有大白话
  • 三类主动提醒
P1 一句话办事
  • 统一任务队列
  • “帮我看 / 帮我盯 / 帮我复盘”
  • 失败自动换路并说人话
  • 数据源与端口全部隐藏
P2 记住你、交付你
  • 判断回顾与纠偏
  • 一页纸报告
  • 语音播报
  • 可转发长图
设计说明：为什么这样改

1. 收口不是删功能。复盘、研究、回测、数据资产都还在，只是从主航道收进“更多”。普通人不该先看到 62 个数据集。

2. 结论先行不是简化。先给“要不要动”，再给三条理由、风险、下一步；专业数据折叠在“看依据”里，想看的人随时能看。

3. 主动不是打扰。只报“跟你有关”的三类：持仓异动、公告风险、观点到期。没事就不说话。

4. 说人话不是去掉专业。术语保留，但点开有大白话解释；数字保留，但每个都能点回来源。
