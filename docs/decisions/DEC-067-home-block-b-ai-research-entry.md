# DEC-067 首页 B 块升级为 AI 研究对话入口（复用 QUOT-454 通道）

- 日期：2026-11-07
- 提出：前端架构师（QUOT-472，触发人 13439731205）
- 状态：已采纳（老板 2026-11-07 在 QUOT-472 选择 A 方案：对话入口；实现见本任务）
- 关联：QUOT-357（聚合搜索面板 / SPEC-HOME-V2 首版 §3）、QUOT-377 / QUOT-378（首页 v2）、
  QUOT-399（既有 AI 通道）、QUOT-454（页级研究助手抽屉）、DEC-045（决策编号顺延规则）
- 影响文件：`docs/specs/SPEC-HOME-V2.md` §3 / §9 / §12-L01（v1.1 修订）

## 1. 背景

SPEC-HOME-V2 v1.0 的 §3.2 与 §12-L01 明确写着：首页 B 块**只做聚合搜索的版式重排**，
文案不得出现「AI」「接入」「联网搜索」——因为当时仓内没有问答通道（QUOT-357 §14-A1
认定「写『问』是骗人的承诺」）。

QUOT-454 之后情况变了：`POST /api/research/{code}/assistant` 已落地，把页面已展示数据的
只读摘要 + 问题交给既有 AI 通道（OpenAI 兼容 / Anthropic / 订阅版 CLI），只回文本、
不回写页面数据。QUOT-472 由老板选 A 方案：B 块从「看起来是输入框的搜索按钮」升级为
**真实的 AI 研究对话入口**，并且要求搜索能力零回退。

## 2. 决定

### 2.1 版式：对话在上，直接搜在下

- B 块主体改为 `HomeResearchChat`：标题「今天，想研究什么？」+ 副标题
  「直接说要研究什么。回答只依据首页已取到的数据，并注明用了哪些、什么时候取的。」；
- 四条起步问题（点击只填进输入框，不发请求）：
  今日市场变化 / 一家公司的基本面·估值·风险 / 产业链新变化 / 研报结论核对；
- 输入：多行 `Textarea` + 发送按钮；Enter 发送、Shift+Enter 换行（输入法合成期间不发送）；
  在飞时按钮变「停止」（`AbortController`）；有对话时才有「清空」；
- 原聚合搜索完整保留在下方「不经过 AI，直接搜」分区：`HomeSearchTrigger`、三行映射、
  最近搜索 chips、`SearchPanel` 模态 overlay 全部原样；`?search=` 深链与 `/` 快捷键不变。

### 2.2 通道：只复用 QUOT-454，不开第二条模型调用

- 前端新增 `askHomeAssistant()`（`frontend/src/api/research.ts:971`），内部直接调用
  `askResearchAssistant(HOME_ASSISTANT_SCOPE, ...)`，`scope` 用 `'home'`（`:941`）。
  后端路由是 `/{code}/assistant`，`home` 只是占位段，后端不按代码取数据；
- 降级文案复用 `describeAssistantError` 的四类（未连接 / 未配置 / 超时 / 上游），
  失败走 `ErrorBlock` + 「重试」，重试不重复追加用户气泡；
- 停止后在对话里追加「已停止本次回答。」，且不渲染来源清单；
- 不新增依赖、不新增 token、不改后端协议、不改搜索三件套的公开入参。

### 2.3 上下文白名单与隐私

`frontend/src/screens/home/homeAssistant.ts` 只导出四类页面已展示字段：

| 数据 | 上限 | 字段 |
|---|---|---|
| 市场（A 块） | 4 格 | `code / name / price / changePct` + `asOf` |
| 自选（C 块） | 20 行 | `code / name / price / changePct` |
| 盯盘快照（F 块） | 10 行 | `code / name / changePct / status` |
| 验证条件（E 块） | 仅条数 | `conditions`（条件正文属私有内容，不进上下文） |

- **持仓（D 块）永不进入**上下文，也不进「本轮来源」；
- 取不到的块写入 `unavailable[]`（`K 线` / `行情` 之外的首页口径），回答可以据此直说缺数。

### 2.4 「本轮来源」必须可核对

- 来源清单在**发请求之前**从 `assistant.sources` 取快照，回答回来后原样渲染，避免页面刷新后
  把「这次用了什么」换成「现在有什么」；
- 每条包含：来源名、项数、`取数 HH:MM`（来自该块 `as_of` / `data_as_of`）与页面链接
  （`/my-stocks?tab=watch`、`/watch`、`/validate`）；指数条没有独立页，写「首页 A 块」；
- 一条来源都没有时显示「本轮未取数：首页这一块还没取到可用的行情，回答只基于你的问题。」
  **不造默认来源、不编造链接**。

### 2.5 明确不做（通道没有的能力，文案就不写）

1. **不承诺联网搜索 / 实时抓取**：通道只把页面上下文发给模型，不做检索、不取新数据；
   副标题与脚注都不出现「联网」。
2. **不承诺后台研究任务**：「先问一句就起研究任务、起前确认、取消写原因」需要
   `pending_research` 一类接口；本仓只有单段续跑 `POST /api/research/{code}/run`
   （`start_run` 只接受已存在的 `(code, day)`，`only` 必须是一个合法段）。没有「意图 → 任务」
   的通道，硬造一个前端确认框只能产出一次不会发生的「任务」，所以本卡不做；真正的研究任务
   入口保持个股深挖页（QUOT-275）。这一条按任务书要求上报，不静默降级。
3. **不把模型输出的数字写回页面**：回答永远只是气泡内文本，脚注固定
   「回答只是解读，行情数字以页面为准，不构成投资建议」。

## 3. 后果

- SPEC-HOME-V2 §3 的旧版式与「禁止出现 AI」红线作废，替换为 v1.1 的对话入口口径；
  文案红线改成「不承诺通道没有的能力」（联网 / 后台任务），其余隐私与口径约束不变；
- 首页 B 块在「未配 Key / 本机未连接」时仍然是可用的入口（对话区给结论 + 重试，
  直接搜照常工作），不再因 AI 通道不可用而整块失效；
- 遗留：本机没有可用的模型 Key（`claude` CLI 路径失效、`codex` 订阅分组不可用），
  「真实模型调用」这条验收项未能完成，已用本机 OpenAI 兼容 stub 打通链路并如实标注，
  待接入真实 Key 后按 `docs/tasks/QUOT-472/README.md` 的复跑步骤补拍。
