# DEC-044 导航新增「我的股票」组：聚合已有持仓/事件日历，自选与提醒登记范围外

- 日期：2026-11-02
- 提出：总经理（QUOT-304，接手前端架构师排队中的结构分组工作）
- 状态：生效
- 关联：QUOT-300（导航补入口）、QUOT-301 / QUOT-302（盯盘 6 时点）、DEC-040（UI-SPEC 19 屏）、
  `docs/UI-SPEC.md` §2、`frontend/src/components/Layout.tsx`、`frontend/src/routes.ts`、
  `frontend/tests/nav-routes.test.tsx`

## 1. 背景

2026-11-01 人类对导航范围拍板「实现 ab」：A 由 QUOT-300/301/302 完成，B（本决策）要求把
「我自己相关」的页面从「市场 / 日志」里抽出来，聚成「我的股票」组，对齐参考侧
`vibe-astock` 的「自选与持仓 / 事件日历 / 提醒」信息架构。

现状（`Layout.tsx` 的 `NAV_SECTIONS`）：我的持仓挂在「日志」组，事件日历挂在「市场」组；
自选与提醒在 `docs/`、路由表、屏幕目录里都没有对应页面。

## 2. 决定

1. 新增一级组 `my-stocks`（显示名「我的股票」），位置在「日志」之后、「验证」之前，顺序为：
   首页 → 市场 → 盯盘 → 复盘 → 日志 → 我的股票 → 验证 → 产业研究 → 个股深挖。
2. 组内只放**已有路由**，不新建页面、不新增接口字段：
   - 我的持仓 → `/positions`
   - 事件日历 → `/calendar`
3. 聚合是移动不是复制：`/positions` 从「日志」移出，`/calendar` 从「市场」移出；
   「日志」组保留交易日志 `/journal`，「市场」组保留 3 段 + 资讯雷达。
4. **自选、提醒不在本轮范围**：产品没有对应页面与接口，本决策不建占位入口、不造假数据。
   自选与提醒的差别只在文案：提醒是参考侧能力，本产品没有；自选若将来落地，再单独立项。
5. 导航一致性测试同步断言新组成员，并把「移动后原组不再重复」写成断言。

## 3. 备选与取舍

| 方案 | 取舍 |
|---|---|
| 把「候选池」改名为「自选」放进本组 | 候选池是复盘程序生成的候选集，不是用户自选；改名会让语义失真，否决 |
| 新建 `/watchlist` 页面承接自选 | 违反本单「不新功能、不新建页面」边界，且无数据模型，否决 |
| 一次性拆掉「日志」组 | 交易日志是独立工作流，保留；只移出持仓，避免过度重构 |
| 保留 `NAV_SECTIONS` 现状只加视觉分组 | 无法解决问题（持仓/日历仍在错误组），否决 |

## 4. 影响

- 侧栏一级组从 8 组变为 9 组（+设置），「市场」由 5 项变 4 项，「日志」由 2 项变 1 项。
- 窄侧栏（rail）下新组与其它组一致：二级展平为图标行，不需要额外样式。
- 路由零变更；深链、IndexedDB 键、后端接口零变更。
- 回滚方式：还原 `Layout.tsx` 的 `NAV_SECTIONS` 与本文，一致性测试同步回退即可。
