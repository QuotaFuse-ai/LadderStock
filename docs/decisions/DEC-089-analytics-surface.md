## 2. 口径（缺数就是 `null` + 原因）

| 指标 | 算法 | 缺数据时 |
|---|---|---|
| 最大回撤 | TWR 净值序列 peak-to-trough | 序列 <2 点 → `null` |
| 夏普 / 年化波动 | TWR 日收益 mean/std × √252（无风险利率取 0） | 样本 <20 或 std=0 → `null` |
| 胜率 | 已实现卖出中 `pnl > 0` 的占比（平局不进分母） | 无已实现 → `null` |
| 盈亏比 | 盈利合计 / abs(亏损合计) | 无亏损或盈利 → `null` |
| 基准 / 超额 | 沪深300 与组合净值**同起同止**；超额 = TWR − 基准 | 本机无指数缓存 → `null` + 原因 |
| 行为分档 | 买入价在当日 `[low, high]` 振幅中的位置（>0.8 追高 / <0.2 低吸），统计各自「买入价 → 第 5 个交易日收盘」 | 当日缺 OHLC → 该笔不计入 |
| 错题本 | 已实现亏损最大前 10 笔（持有天数 = 卖出前最早一笔买入的间隔） | 无亏损 → 空列表 |

不联网取指数、不拿别的指数或估算顶替、不补 0——沿用 DEC-006 与全仓
「取不到就如实说」的红线。

## 3. 边界与红线

- **只读**：不写流水、不改持仓、不动任何库；DuckDB 一律 `read_only=True`；
- **只走现役闸门**：`privacy_read_guard`（回环 + Host 白名单）+ `no-store`，
  不新增鉴权体系；写面不存在（本面没有 POST）；
- **引擎位置按先例处理**：`analytics/engine.py` 是域模块（与 `watch/brief.py`
  同族——它同样只读隐私库做聚合），不在 `mcp / web / ai` 三个受控面上；
  Web 出口文件本身不 import `journal.*`，`check_privacy` 扫描口径不需要新增白名单；
- **响应内容**：围绕本人复盘的聚合结果 + 按标的归因 + 单笔已实现明细（错题本）。
  与 radar 的 trades 读面同级，不出现在任何非本机入口。
