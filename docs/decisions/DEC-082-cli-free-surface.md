# DEC-082：全局去 CLI / 去手动面——用户可见面零命令，自动化兜底（QUOT-559）

日期：2026-11-12
关联：QUOT-559（拆自 QUOT-519）、DEC-080（ensure-on-open，S2 后端口径）、
DEC-081（端口冲突安全处置）、QUOT-558（S5 子模块健康弹窗 + 确认重启）、
QUOT-538（本页数据同步双命令）、QUOT-552（首页工作台）、§5.6（不回落演示数据）
状态：已定稿

## 背景

QUOT-538 落地了「本页数据同步」双命令面板，但面板把 CLI 命令原文（`ldst industry
list` / `ldst sync industry`）、打印 argv、「复制命令」「在终端运行」一起摆给了用户；
全站约 26 屏的空态也在指引「先运行 ldst sync / qfw run」。对普通用户这是把实现
细节外包给用户：既读不懂，也不该读。DEC-080 的 S2 ensure-on-open 已在后端把
「打开页面即补齐数据」做成能力，前端却没有用它——用户仍被要求手动触发。

本单（QUOT-559）把前端改成「自动就绪」：数据由页面自动补齐，用户只看白话进度
与结果；技术参数只在开发态可见。

红线（派单正文，逐条保留）：不改 frontend/src 迁就测试（不删断言 / 不用
expect(true) 换绿）；不 sleep 掩盖偶发；禁止整文件 skip；不前端重算指标；不硬编码
模型清单；不回落演示数据顶替真实失败（§5.6）；不动 backend/ 与 CI workflow；密钥
不进前端 / 日志 / 提交；不动 5950/8000/9100/9000 端口。

## 决策

1. **PageCommandBar 自动就绪，面板只说人话**：打开「本页数据同步」面板即触发
   S2 ensure-on-open 自动补取，按钮态收敛为「立即开始 / 进行中」；删除打印
   argv、「复制命令」「在终端运行」三个手动面元素。演示态下整颗命令栏不渲染
   （演示数据无需同步，同步入口本身是技术面）。展示层保留 `sanitizeCliText`
   兜底：即使后端 detail 里混入命令串，到达用户眼前也先清洗。
2. **空态文案规范：自动补取 + 页内一键，不写命令**：全站空态统一为
   「打开本页会自动补取并生成；也可以点右上角『本页数据同步』立即开始，完成后
   点『重新检查』」句式，禁止出现 `ldst ` / `qfw ` 命令串与「复制命令」类指引。
   冷启动即自动 ensure，用户零操作等到数据；一键入口只给「等不及的人」。
3. **技术徽标收敛**：`DemoStateBadge` 徽标正文统一「演示数据」，来源细节
   （网址开关打开 / 设置页「虚拟数据」开关）移入 hover `title`；
   `?state=` 强制态水印「演示态：加载中」去掉括号内技术参数，且仅在
   `import.meta.env.DEV` 渲染——生产构建不出现任何 URL 参数回显。
4. **真失败接 S5，不回落演示（§5.6）**：同步 / 补取失败时走 QUOT-558 的健康
   弹窗一键「确认重启」，不弹命令、不切演示数据。`controlCommand` 409 / 超限
   错误文案白话化（「已有页面任务在执行…」「超出单次同步上限…」）；
   `describeResearchError` 的 404 按后端 `detail` 语义区分「未知证券代码 /
   还没跑过研究 / 接口未接入」，not-connected 明示「本机服务未连接」+ 重试指引。
5. **零 CLI 守卫测试防回潮**：新增 `frontend/tests/quot-559-no-cli-surface.test.ts`
   ——walk 全 `src`（.ts/.tsx，**注释一并纳入扫描**：注释与用户可见字符串在同一次
   copy/paste 里互相渗��，分家扫不住），断言 `ldst\s+\w|qfw\s+\w|复制命令|在终端`
   零命中；白名单仅 `ease-ldst` / `ldst-num` 两个设计系统类（动效曲线与等宽数字，
   非 CLI 语义）。既有测试把「必须有 argv / CLI」类断言**反转为「必须没有」+ title
   断言**，保留验证价值，不删断言。

## 后果

- 用户可见面零 CLI：全局 grep `ldst\s+\w|qfw\s+\w|复制命令|在终端` 对 src 零命中
  （守卫测试固化）；「先运行 ldst sync」类指引全部消失。
- 命令面板从「手动操作台」变为「白话进度面板」：power user 需要精确命令时，
  去终端自己敲（CLI 是后端契约，前端不再代教）。
- 后续新屏写空态时按第 2 条句式，守卫测试会在引入命令串时直接红灯。
- 浏览器取证：六页面（home / market / news / review-ai / settings / weekly）
  before/after 截图随 issue 评论交付。
