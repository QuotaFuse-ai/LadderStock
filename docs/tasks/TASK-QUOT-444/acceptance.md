## 三、本轮发现并修复的缺陷

旧产物（`mode=parsed`）把模型返回的**整包 JSON 原样写成一段叙述**，
页面照原样渲染就是一屏花括号，读者看不到任何结论；且该串本身是坏 JSON
（数组收尾多写一个引号 `"]"`，`JSON.parse` 报 `Expecting ',' delimiter`）。

修复（仅展示层，未改写任何已存数据）：新增 `unwrapNarrativeJson` 逐行识别
`{"键": …}` 包装串，把字符串/字符串数组拆成段落；文案一字不改、不解释字段含义，
解析不出来即原样返回。`artifactMarkdown` 与「研究摘要」两处接入，
新增 `tests/research-narrative-unwrap.test.ts`（7 例）锁定行为。
