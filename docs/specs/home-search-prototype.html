C-21 入口：默认 / hover / focus-visible

挂载在 PageHeader actions 槽位（PageShell.tsx:26-40），「刷新全部」左侧。放大 2× 展示。

默认

border-border-strong + bg-sunken，占位文案 text-text-muted

h 40px = control-h-lgw 256pxradius 8pxicon left 8px

--ldst-control-h-lg 的 usage 注释原文即「主操作按钮 lg / 搜索框」（tokens.css:111）——这一档本来就留给它。

hover

只换描边与占位文字颜色，底色不变

border-strong → accentmuted → secondaryduration-fast 120ms

底色保持 sunken：体系里没有 sunken 的 hover 档，不新造；可点击性由描边变亮承担（accent vs sunken 实测 5.9:1 / 6.3:1）。

focus-visible（键盘到达但未打开）

全局焦点环 + 键帽位换成 Enter 提示

ring: 2px bg + 2px #6ba1ffouter vs surface 6.80:1

Tab 路过不弹面板（规格 §4.5）：焦点环 + 键帽提示承担同等可发现性，不抢占遮罩。
