## 0. 一句话与范围

首页从「收盘后的市场体检报告」改成「开盘前 5 分钟的工作台」：**先看大盘在哪，再决定今天研究什么，
然后只看自己的票（自选 + 持仓）**。四块按参考页顺序纵向排列，原有三块（情绪温度 / 连板梯队 Top 10 /
题材强度 Top 5）从首页移除、信息不丢，两块首页独有（待办 / 最近异动）保留并下移。

**覆盖**：页面骨架与顺序、逐块线框、逐块字段表（要哪些字段 / 从哪来 / 拿不到显示什么）、
逐块状态矩阵、整屏六态与块级四态的关系、验收清单、需上报的决策点。

**不覆盖**：`GET /api/indices` 与 `GET /api/watchlist` 的实现与字段命名（QUOT-377 S2 后端子任务）、
`frontend/src/lib/search*.ts` 的接口形状（硬约束：零改动）、`/market` `/positions` 等来源屏自身的版式。

## 1. 页面骨架

### 1.1 块顺序与栅格

```
PageHeader：首页 · 摘要 · [刷新全部]                       （唯一主操作在最右，无搜索入口）
├─ offline / partial 提示条（整屏级，条件出现）
├─ A 大盘与全球指数条            全宽  SectionCard          8 格 = 4 列 × 2 行
├─ B 今天，想研究什么？          全宽  Card（研究入口卡）
├─ C 我的自选                    全宽  SectionCard（DataTable 4 列）
├─ D 我的持仓                    全宽  SectionCard（汇总 5 列 + 逐条 6 列）
├─ grid gap-4 grid-cols-1 desk:grid-cols-12
│   ├─ E 待办         desk:col-span-7
│   └─ F 最近异动     desk:col-span-5
└─ 页脚口径行（text-caption text-text-muted）
```

- **A/B/C/D 四块各自满宽纵向堆叠，只有 E/F 并排**。这不是审美选择，是算术结论：
  任务要求的持仓逐条列是**六个单行字段**（名称 / 代码·股数 / 现价 / 市值 / 持仓盈亏 / 当日盈亏），
  在 `--ldst-row-h` 38px 的既有行高档里每列只能放一行，列宽下限合计
  `名称 176 + 176 + 112×4 + 单元格左右内距 24 = 824px`；
  而 `col-span-7` 在 1280 档只有 577px（§1.2），名称列会被压到 46px——文字直接叠字。
  参考页能并排，是因为它把「名称 + 代码·股数」「现价 + 涨跌」压成**两行格**（见 §12-L06）。
  我们不照抄两行格：那要么新增行高档（违反 §7.3 密度只改行高的既有刻度），
  要么把 `DataTable` 换成手写网格（违反 §6.2 唯一表体）。
- **不再出现**：`TemperatureBar`、5 张 `MetricCard`、`今日连板梯队 Top 10` 表、`题材强度 Top 5` 卡
  （现 `HomeScreen.tsx:396-474,476-513,573-579`）。移除不等于丢信息，见 §1.3。
- **不再出现**：`PageHeader` 右侧的搜索入口（QUOT-357 `HomeSearchTrigger`）——它搬进 B 块，
  同一组件同一契约，只是换了挂载位置；页头右侧恢复为「刷新全部」唯一主操作。
- 块顺序按任务书（指数条 → 提问面板 → 自选 → 持仓）。参考页把提问面板放在自选 / 持仓**之下**，
  任务书把它列为第 2 块——按任务书执行（老板拍板的顺序），差异记入 §12-L06 备注。

### 1.2 几何（可复核，不是估的）

| 视口 | 侧栏 | `main` 可用宽 | 12 列单列 | `col-span-7`(E) | `col-span-5`(F) | 指数格（4 列，A/C/D 满宽） |
|---|---|---|---|---|---|---|
| 1440 | 232 | 1160 | 82 | 667 | 477 | 271 |
| 1280（`--ldst-bp-base`） | 232 | 1000 | 68.7 | 577 | 407 | 232 |
| 1024（`--ldst-bp-min`，`rail:` 档侧栏 56） | 56 | 920 | — 单栏 | 920 | 920 | 212 |

- 算法：`main` = 视口 − 侧栏 − `px-5`（24×2）；`max-w-table` 1296 在三档都未触发，不额外缩宽。
  满宽块内的格宽 = (`main` − 左边条 3 − `p-3` 内距 24 − 3×`gap-4` 48) ÷ 4。
- 指数格内容下限：点位 `12,641.86` = 9 字符 × 12.05px（20px 等宽）= 108px + `p-3`（12×2）= **132px**。
  4 列档最窄 212px，富余充足。**单排 8 格在 1440 只有 128px/格、1280 只有 108px/格，都放不下 20px 点位**
  （参考页能做到单排，因为它的点位是 14px：9 × 8.4 + 24 = 100px ≤ 108px），见 §12-L02。
- C 块 4 列在满宽下名称列吃掉剩余宽（1440 档 824px）——与现网 `今日连板梯队 Top 10` 的
  名称列行为完全一致（`DataTable` 无 `width` 的列均分剩余），不是新问题，也不为此加临时列。
- D 块两张表都在满宽下成立：汇总表 `88 + 剩余 + 112×3`（剩余 712），
  逐条表 `剩余 + 176 + 112×4`（名称列 512，≥ 176 下限）。
- E/F 在 `rail:`（1024–1279）单栏满宽，不横向压缩。

| 移除块 | 信息落点 | 首页是否留出口 |

### 2.1 线框

```
┌─ SectionCard（tone=neutral，bodyClassName="p-3"）────────────────────────────────────────┐
│  大盘与全球指数        快照 · 不自动刷新   ● 数据完整   13:41   [刷新]                     │
│ ┌──────────────────────┬──────────────────────┬ … 4 列 …┐                                │
│ │ 上证指数  A 股        │ 沪深300  A 股        │         │  ← 名称 text-caption secondary  │
│ │ 3,813.79              │ 4,317.25             │         │  ← 点位 text-section 600 .ldst-num │
│ │ +0.05% ↑             │ +0.16% ↑             │         │  ← 涨跌 SignedNumber caption    │
│ └──────────────────────┴──────────────────────┴─────────┘                                  │
│ ┌──────────────────────┬──────────────────────┬ … 4 列 …┐                                │
│ │ 道琼斯 美股           │ 纳斯达克综合 美股     │ 恒生指数 港股 │ 恒生科技 港股              │
│ │ 51,570.09             │ 24,707.81            │ —            │ —                        │
│ │ +0.09% ↑             │ +0.14% ↑             │ 源未接入      │ 源未接入                  │
│ └──────────────────────┴──────────────────────┴─────────┘                                  │
│ 脚注：指数为行情快照，不是逐笔实时；港股 / 美股指数源未接入时该格显示「—」与原因，不补 0。    │
│       源：指数快照 + 美股指数快照                                                             │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```

- 每格：`div` 非卡（不叠第二层阴影，靠 1px `border-border` 分界，§7.3 阴影唯一用法），
  `rounded` + `border border-border bg-surface` + `p-3` + `min-h-metric`（96px）+
  `flex flex-col justify-between gap-1`。
- 网格：`grid grid-cols-2 gap-4 desk:grid-cols-4`（≥1024 起即 4 列 × 2 行；8 格在 4 列下自然回流成
  两行；两列只服务 <1024 的非支持档，作为兜底存在）。**不做单排 8 格**，算术与解锁条件见 §1.2 / §12-L02。
- 市场后缀（`A 股` / `港股` / `美股`）是 `text-caption text-text-muted` 的行内标签，
  不是 `Badge`——它是身份说明不是状态，用 Badge 会把 8 格变成 8 个胶囊，噪声大于信息。
- 顺序固定为白名单顺序：上证 / 沪深300 / 深证成指 / 创业板指 → 道琼斯 / 纳斯达克综合 →
  恒生指数 / 恒生科技。顺序由后端 `cells[]` 给出，前端不排序（§1-1「程序算数」）；
  前端只保证「给几格渲染几格」。

### 2.2 字段表

> 字段名以 `GET /api/indices` 实际契约（`frontend/src/api/radar.ts:343` `IndicesPayload`）为准：
> 八格在 `cells[]` 里，每格 `{ code, market, name, available, price, change, change_pct, prev_close, as_of, reason }`。
> **QUOT-471 起**：`cells[]` 恒为 8 格（A 股 4 + 美股 2 + 港股 2），美股两格由 `tickhub_us` peer 的
> `th_us_get_quote` 供数（每首页取数 = 2 次调用，一 symbol 一次，无按格扇出）；港股两格**无合规源**，
> 恒为 `available=false` + 「源未接入」占位（DEC-006 闸门 4：无源不得自采）。

| 上屏项 | 需要的字段 | 从哪来 | 拿不到时显示 |
|---|---|---|---|
| 指数名 | `name` | `GET /api/indices` → `cells[].name`（后端白名单写死 8 格：4 A 股 + 2 美股 + 2 港股） | 该格整体降级为「源未接入」占位格（§2.3），不显示名字猜指数 |
| 市场后缀 | `market`（枚举 `SH` / `SZ` / `BJ` / `HK` / `US`） | 同上 `cells[].market` | 不显示后缀行（后缀是修饰信息，缺失不阻塞读数） |
| 点位 | `price` | 同上 `cells[].price`（A 股来自 `index_quote`，美股来自 `index_quote_us`） | `—`（`MISSING`），旁注「点位未取到」；**不得显示 0**（§8） |
| 涨跌幅 | `change_pct` | 同上 `cells[].change_pct` | `—` + 无箭头；点位仍照常显示（两者是独立事实，不互相抹掉） |
| 缺格原因 | `available` / `reason` | 同上 `cells[].available` / `cells[].reason`；`available=false` → 「源未接入」，否则「点位未取到」 | 第三行落到二者之一，不留白（§2.3） |
| 「快照，不是逐笔实时」 | `freshness` / `data_as_of` | 信封公共字段 → `SourceBadges` + `formatTime` | `freshness` 未给 → 中性徽标「新鲜度未知」（§5.7，不得静默不渲染） |
| 脚注里的源名 | `datasets[]`（数据口径）与 `price_source` | 信封 → 中文标签映射（§5.8，后端 key 不直显）；QUOT-471 起脚注列 `指数快照 + 美股指数快照` | 脚注只保留固定口径句，不编源名 |

## 3. 块 B：今天，想研究什么？（研究入口卡）

### 3.1 版式与边界


- **只做版式重排**：`HomeSearch`（装配件）/ `useHomeSearch`（状态机）/ `SearchPanel`（呈现件）
  三件套与 `lib/searchCore.ts` / `searchIntent.ts` / `searchRoutes.ts` 的公开入参、返回形状
  **零改动**。本块的改动面只有两处：① `HomeSearchTrigger` 从 `PageHeader.actions` 移进本卡；

- 结果面板**继续是既有的模态 overlay**（`createPortal` + `useModalChrome`，焦点陷阱 / Esc /
  滚动锁 / 关闭后焦点回入口）。不在本块内联渲染结果：把 `SearchPanel` 改成内联变体等于
  把同一套键盘与读屏契约实现第二遍，直接违反 §1-7「一份实现」，也超出「只做版式重排」的范围。
- 三行映射文案与 `SearchPanel` 的 `GUIDE_ROWS` **同源**（同一常量导出复用，不复制字符串）。
- 最近搜索 chips 取 `useHomeSearch` 已产出的 `model.recent`，上限 4 枚、`text-caption`、
  `rounded-xs border border-border px-2 h-5`（与面板内既有 chip 同一组类），点击即填入关键词并开面板。

### 3.2 文案红线（与参考页的唯一实质差异）

参考页这块写着「直接说要研究什么。AI 会按需要联网搜索、取数、计算」并挂「请接入 AI」按钮。
**我们不照抄**：仓内没有问答通道（QUOT-357 规格 §14-A1 已裁定「写『问』是骗人的承诺」），
`AiConnectDialog` 接的是复盘 / 周报的段落生成，不是自由问答。因此：

- 标题「今天，想研究什么？」保留（老板拍板的参考页文案，且我们的出口确实是个股深挖 / 行业详情 / 资讯）；
- 副标题**必须**落在真实能力上：「查数据、找证据、梳理思路」；
- 卡内**不得**出现「AI」「接入」「联网搜索」类按钮或承诺；现有「接入 AI」入口保持在侧栏底部
  与设置 → AI 接入（UI-SPEC v1.5），首页不新增第三个入口；
- 若老板要的是真问答面板，那是新能力（新端点 + AI 通道 + 隐私边界），不在本规格内 → §12-L01。

### 3.3 状态矩阵

| 状态 | 判据 | 表现 |
|---|---|---|
| normal | 已登录本机服务 | 满卡 |
| 本机服务未连接 | 整屏 `offline` | 触发条照常可点（点击后面板自己给「未接入」结论），卡内三行映射不变；**不灰化、不隐藏本块**（它是入口不是数据） |

| 面板内各组状态 | 沿用 QUOT-357 既有规格（组级骨架 / 「该组暂不可用」/ 空态三条引导 / 1.2s 慢提示） | **本规格不改，不重复定义** |

## 7. 整屏六态与块级四态的关系

优先级沿用 `lib/pageState.ts`：`error > offline > partial > loading > empty > normal`。

| 整屏态 | 判据（v2，五路：indices / watchlist / positions / watch / validation） | 表现 |
|---|---|---|
